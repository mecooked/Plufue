## 🔹 О проекте
Многостраничный корпоративный сайт-портфолио, разработанный с нуля (native-разработка без использования готовых CMS). Проект включает в себя клиентскую часть со сложными интерактивными анимациями и полноценную серверную часть (админ-панель) для управления контентом и заявками клиентов.

**Главная задача проекта:** создать премиальный визуальный опыт для пользователя с помощью библиотеки GSAP и обеспечить владельца сайта безопасным и удобным инструментом для модерации портфолио.

## ✨ Ключевой функционал (Что реализовано)

### 🎨 Клиентская часть (Frontend)
- **Сложные GSAP-анимации:** реализована бесконечная разнонаправленная прокрутка колонок портфолио. При наведении курсора скрипт плавно замедляет анимацию (timeScale) для комфортного изучения работ.
- **Интерактивная фильтрация:** мгновенная сортировка проектов по категориям (Брендинг, Дизайн, Сайт) без перезагрузки страницы средствами JavaScript.
- **Динамические страницы:** генерация уникальных страниц (листьев) для каждого кейса на основе единого шаблона `project.php?id=X`.
- **Custom UI:** кастомные эффекты наведения (с использованием cubic-bezier).

### ⚙️ Серверная часть (Backend & Admin)
- **Полноценный CRUD для портфолио:** возможность добавлять новые проекты, загружать обложки на сервер и выводить их в клиентской части.
- **Система обработки лидов:** сбор заявок от клиентов через форму, их валидация и вывод в удобном виде в панели администратора (с возможностью удаления обработанных).
- **Безопасность:** защита базы данных от SQL-инъекций с помощью подготовленных запросов (Prepared Statements) и предотвращение XSS-атак.
- **Скрытая авторизация:** защищенный вход в админ-панель на основе сессий.

## 🔹 Стек технологий
* **Frontend:** HTML5, CSS3, JavaScript (ES6+).
* **Backend:** PHP 8 (Native).
* **База данных:** MySQL (MariaDB).
* **Анимации:** GSAP (GreenSock Animation Platform).
* **Архитектура:** Динамическая маршрутизация (GET/POST запросы), модульная структура.
