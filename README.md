## 🔹 О проекте
Портфолио для веб-агенства "Plufue" - многостраничный сайт-портфолио с модерацией контента. <br> <br> 
Сайт полностью **поддерживает администрацию** вида CRUD (CRUD - создание, чтение, редактирование, удаление) **на основе PHP**. <br> Админ-панель способна:
* Создавать, редактировать, удалять Проекты - их содержимое от тегов до фотографий на личной странице каждого проекта;
* Менять расположение Проектов - их места внутри секций;
* Просматривать и отвечать на Заявки клиентов;
